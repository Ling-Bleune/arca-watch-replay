# 아카라이브 같이 보기 다시 보기 — v0.5.5

종료된 게시글에서 **왼쪽 YouTube 영상 / 오른쪽 채팅** 화면을 열고, 보존된 댓글을 작성 시각에 맞춰 재생하는 Tampermonkey 스크립트입니다. `/b/` 일반 게시글과 `/r/` 방 경로에서 실행됩니다.

## 설치

1. Tampermonkey에서 이전에 설치한 스크립트의 편집기를 엽니다.
2. 기존 코드 전체를 `arca-watch-replay.user.js`의 내용으로 교체하고 저장합니다. 이전 버전과 새 버전을 동시에 켜지 마세요.
3. 대상 게시글을 새로고침합니다.
4. 오른쪽 아래 **▶ 같이 보기 다시 보기**를 누릅니다.

새로 설치한다면 Tampermonkey의 **새 스크립트 만들기**에 전체 코드를 붙여 넣으면 됩니다.

v0.5.1은 첫 실행에서 댓글 50개와 빈 채팅 안내만 표시되던 문제를 수정합니다. 화면에 있는 댓글을 무조건 1페이지로 가정하지 않고 실제 `cp=1` 응답으로 페이지 범위를 확인합니다. 이전 버전에서 저장한 댓글·설정은 유지하고 확인되지 않은 페이지 캐시는 다시 읽으므로 **수집 초기화를 누를 필요가 없습니다.**

## 사용

종료된 게시글의 `.relay-card .og-href`에서 YouTube 주소를 자동으로 읽습니다. 예시 게시글에서는 `OHEJ4NyW6-g`를 확인했습니다.

현재 화면의 댓글은 즉시 읽습니다. 종료된 게시글에 **수정일**이 있으면 이를 끝 시각으로 사용해 마지막 페이지를 따로 읽지 않습니다. `/r/` 방에서는 원본 `/b/` 게시글을 한 번 확인합니다. 수정일이 없을 때만 **마지막 댓글 페이지**로 끝 시각을 추정합니다. 이후 현재 재생 위치 앞쪽 약 **90초**, 뒤쪽 약 **60초** 범위만 미리 읽습니다. 고배속에서는 앞쪽 범위를 배속에 맞춰 늘립니다. 한 구간에서 중심 페이지와 앞뒤 각각 최대 2페이지까지 읽으며, 재생이 진행될 때 다음 구간을 준비합니다. 처음부터 전체 페이지를 수집하지 않습니다.

화면의 댓글 50개는 페이지 번호가 확정되지 않은 표시용 데이터로 읽습니다. 처음 시간 구간을 찾을 때 1페이지를 한 번 요청하고, 이후에는 요청으로 확인한 페이지 범위만 캐시합니다. 이전 캐시에서 확인 표시가 없는 페이지도 한 번 다시 확인합니다.

멀리 탐색하면 댓글 페이지의 시간 범위를 비교해 해당 구간을 찾습니다. 아직 시간 범위를 모르는 페이지를 이진 탐색으로 일부 읽을 수 있습니다. 페이지 번호를 순서대로 전부 읽지는 않습니다. 요청은 한 번에 하나씩, 시작 시각 기준 최소 **1.5초** 간격을 두며, 이미 읽은 페이지는 캐시를 사용합니다. 화면을 닫으면 진행 중인 수집도 중지합니다.

전체를 파일로 보관하고 싶을 때만 옵션의 **전체 댓글 보관**을 누르세요. 이 수집도 요청 간격을 지키며 최대 500페이지까지 처리합니다. 수집 중에는 같은 버튼으로 중지할 수 있습니다. **JSON 내보내기**만 누르면 지금까지 읽은 댓글만 저장됩니다.

채팅창 상단 **설정** 버튼을 누르면 설정 창이 열립니다. 싱크는 **영상이 실제로 끝난 시각 − 영상 전체 길이**로 계산합니다. 예를 들어 90분 영상이 실제로 21:30에 끝났다면 영상 0초는 20:00에 해당합니다. 방을 19:00에 미리 만들었어도 이 시간은 싱크에 섞이지 않습니다.

기본 끝 시각은 **종료된 원본 게시글의 수정일**입니다. 종료 처리 때 수정일이 갱신되는 경우 마지막 댓글보다 적절한 기준입니다. 종료 후 본문을 다시 수정했다면 설정에서 **영상이 실제로 끝난 시각**을 직접 보정하세요. 수정일이 없으면 마지막 댓글을 임시 기준으로 사용합니다. 영상 전체 길이는 YouTube 플레이어에서 자동으로 읽으며, 처음에는 길이가 확인될 때까지 채팅 싱크 계산을 기다립니다. **게시글 수정일에 영상 끝 맞추기**, **마지막 댓글에 영상 끝 맞추기**로 기준을 바꿀 수 있습니다. 직접 지정한 끝 시각은 댓글 수집으로 덮어쓰지 않습니다.

- 영상에서 재생·일시정지·탐색하면 채팅도 같은 위치로 이동합니다.
- 평소에는 채팅 하단에 로딩 표시나 빈 상태 칸을 두지 않습니다. 영상 위치를 30초 넘게 옮겨 아직 확인하지 않은 댓글 구간을 찾아야 할 때만 **채팅 버퍼링 중… · 이동한 위치의 채팅을 찾고 있습니다.**를 표시합니다. 해당 구간을 찾으면 즉시 숨기며, 이후 주변 댓글 선행 수집은 조용히 계속합니다. 초기 로딩·일반 재생·이미 읽은 구간으로의 탐색·전체 보관 중에는 표시하지 않습니다. 탐색 중 요청 실패는 **채팅 찾기 지연 · 설정에서 다시 확인**으로 표시하고, 일반 요청 오류는 설정 창 안에서 확인합니다.
- 설정 버튼은 채팅창 맨 위에 있으며, 설정 창은 영상과 채팅의 배치를 밀어내지 않습니다. 바깥 영역이나 **닫기**, Escape로 설정 창을 닫습니다.
- 채팅 시간 보정이 **+10초**이면 같은 댓글이 영상에서 10초 일찍 나타납니다. **-10초**이면 10초 늦게 나타납니다.
- 별도의 탐색바는 제거했습니다. 일반 재생과 탐색에는 YouTube의 조절기를 사용합니다. 별도 타이머를 선택할 때만 설정 창 안에 타이머 조절기가 나타납니다.
- **자동 스크롤**을 끄면 채팅을 읽는 동안 자동으로 아래로 이동하지 않습니다.
- 채팅을 위로 스크롤하면 자동 따라가기가 멈춥니다. 맨 아래로 내려오면 다시 켜집니다. 휠·터치·스크롤바·키보드 이동을 지원합니다.
- 자동 스크롤은 아카콘 로드나 창 크기 변경으로 채팅 높이가 변해도 바닥에 맞춥니다. 기존 댓글 요소를 재사용해 아카콘을 매번 다시 만들지 않습니다.
- 화면에는 현재 위치까지의 최근 150개를 표시하고 전체 댓글은 보관합니다. 시작 전에 달린 댓글도 준비 채팅으로 표시합니다.
- 설정 창의 **게시글로 돌아가기**로 다시 보기 화면을 닫습니다. 설정 창이 닫힌 상태에서 Escape를 눌러도 게시글로 돌아갑니다.
- 채팅 폭은 원본 CSS와 같은 **24rem**입니다. 원본과 같은 991px 이하 화면에서는 영상 아래에 채팅을 배치하고 화면 폭을 사용합니다.
- 이미지·영상 아카콘은 원본 화면처럼 **50×50px**로 표시합니다. 한 댓글의 여러 아카콘은 가로로 여백 없이 붙입니다.

YouTube 임베드가 제한되거나 다른 탭의 영상을 사용하는 경우 **별도 타이머**로 바꾸고, 영상 전체 길이(초)와 재생 위치를 직접 입력해서 영상과 타이머를 맞출 수 있습니다. YouTube 자동 동기화는 공식 [IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)를 사용합니다.

## 보관과 가져오기

수집한 댓글, 영상 주소, 끝 시각, 영상 길이, 시간 보정은 게시글별로 브라우저 localStorage에 저장됩니다. `/b/`와 `/r/`는 같은 게시글의 저장 데이터를 공유합니다. 이전 v0.2/v0.3의 댓글 캐시와 JSON은 읽을 수 있으며, 이전 시작 시각과 보정값은 새 끝 기준으로 전환됩니다.

**댓글·페이지 캐시는 마지막 사용 후 24시간이 지나면 자동 정리합니다.** 영상 주소와 끝 시각·시간 보정 설정은 유지합니다. 게시글을 열 때, 그리고 스크립트가 실행되는 동안 1분마다 만료된 캐시를 확인합니다. 다시 보기 중인 게시글은 사용 시각을 갱신해 유지합니다. 브라우저가 닫혀 있으면 다음에 대상 게시글을 열 때 정리합니다. 다시 방문하면 필요한 댓글을 다시 읽습니다. 저장 시각이 없는 구버전 브라우저 캐시는 업데이트 후 한 번 정리하며 설정은 보존합니다. 내려받은 JSON 파일은 정리 대상이 아닙니다.

**JSON 내보내기**로 전체 데이터를 파일에 보관할 수 있습니다. **JSON / 저장 HTML 가져오기**는 같은 게시글의 파일 여러 개를 합칩니다. HTML의 스크립트는 실행하지 않습니다. v0.1 JSON은 형식이 달라 직접 가져오지 않으므로 댓글을 다시 수집해 주세요.

Chrome에서 저장한 HTML에는 이미지 아카콘 주소가 로컬 파일 경로로 바뀌어 있을 수 있습니다. 이 경우 `[아카콘]`으로 표시합니다. 온라인 게시글에서 전체 댓글을 다시 불러오면 CDN 주소를 확보할 수 있습니다. 이미지 아카콘과 무음 반복 영상 아카콘을 모두 지원합니다. CDN 주소가 만료되거나 미디어를 불러오지 못하면 `[아카콘]`으로 표시합니다.

## 검증 범위

사용자가 제공한 두 저장 파일을 기준으로 구현했습니다.

- 종료된 게시글: 정확한 댓글 선택자, UTC `datetime`, YouTube 주소, 댓글 페이지 링크를 확인했습니다. 저장 파일의 댓글 50개를 읽었습니다.
- 진행 중인 방: `relay-frame-area`, `relay-chat-area`, `relay-message-area`, YouTube URL과 방 시작 시각을 확인했습니다. 이 파일의 최근 채팅에는 작성 시각이 없어 시간축을 임의로 만들지 않습니다. 다시 보기에는 일반 게시글의 시간 정보가 있는 댓글이 필요합니다.
- 외부 네트워크를 차단한 로컬 브라우저 테스트에서 제공 HTML의 수정일을 끝 시각으로 읽기, 수정일이 있을 때 끝 기준 확보용 마지막 페이지 요청 생략, 끝 시각 수동 보정과 기준 전환, 아카콘 3개의 50px 크기와 0px 간격, 24rem 채팅 폭, 설정 창과 Escape, 탐색바 제거, 타이머 길이 입력, 전체 보관, 자동 스크롤, 모바일 설정 창을 검증했습니다.
- 100페이지 모의 댓글에서 수정일이 없을 때 마지막 댓글 기준 추정, 초기 전체 수집 방지, 페이지 경계 선행 수집, 먼 탐색의 제한된 요청 수, 요청 간격과 단일 요청, 정지 중 수집 범위 제한, 캐시 되감기, 늦은 높이 변경 후 바닥 스크롤, 위로 휠 스크롤할 때 멈춤과 위치 유지·맨 아래에서 재개, 자동 스크롤 해제, 화면 종료 시 취소를 검증했습니다.
- 테스트의 댓글 페이지 응답과 YouTube 플레이어는 모의 구현입니다. 실제 사이트의 HTTP 응답과 YouTube 영상 재생은 이 환경에서 검증하지 못했습니다.
- v0.5.1 회귀 테스트에서는 기본 URL에 마지막 구간의 댓글 50개가 표시된 첫 실행, 지연된 YouTube 길이 응답, 이전 버전의 잘못된 1페이지 캐시를 재현했습니다. 초기화 없이 실제 1페이지를 한 번 읽고 채팅이 나타나는지 검증했습니다. 제공 HTML이 로컬에서 없어졌을 경우 일반 UI 테스트는 당시 확인한 구조의 모의 HTML을 사용합니다.

로그인이나 접근 제한 페이지가 반환되면 수집을 멈추고 이유를 표시합니다. 삭제된 댓글, 게시글에 보존되지 않은 채팅, 비공개·삭제된 영상은 복구하지 않습니다. 게시글에 댓글을 작성하지 않는 읽기 전용 기능입니다.
